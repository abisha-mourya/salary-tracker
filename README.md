# Salary Tracker

A beginner Python project completed as part of the freeCodeCamp Python curriculum.

## Description

This project uses an `Employee` class to manage employee details, job levels, and salaries. It validates employee information and applies salary rules when an employee's level changes.

## Concepts Used

- Classes and objects
- Encapsulation
- Properties and setter methods
- Type checking and validation
- Conditional statements
- Dictionaries
- Exception handling
- `__str__()` and `__repr__()` methods

## Features

- Stores employee names and job levels
- Assigns base salaries according to job level
- Updates salaries when employees are promoted
- Prevents employees from moving to a lower level
- Validates salary and job-level changes
- Displays employee information

## Technologies

- Python 3
